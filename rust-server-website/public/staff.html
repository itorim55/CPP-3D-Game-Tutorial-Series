O Código do Moderador

Todos os membros da equipa assinam e cumprem este código. Violações resultam em remoção imediata da equipa — sem exceções.

1. Zero vantagens in-game. Admins que jogam a wipe usam uma conta separada sem poderes, ou não jogam de todo. Nunca se dá spawn a itens numa wipe ativa, nunca se usa noclip/vanish para ganhar vantagem, nunca se espreita a base de ninguém "só para ver".
2. Provas sempre. Nenhum ban por cheating sem gravação. As provas são guardadas e, sempre que possível, publicadas — como faz o camomo_10.
3. Bans públicos. Todos os banimentos aparecem na lista pública abaixo, com motivo e o admin responsável. A comunidade pode contestar qualquer decisão no Discord.
4. Neutralidade total. Um admin nunca modera situações que envolvam a própria equipa/amigos — passa o caso a outro membro da staff.
5. Respeito sempre. Mesmo com cheaters e tóxicos: profissionalismo. Nós representamos o servidor.
